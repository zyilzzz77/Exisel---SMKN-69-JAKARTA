PETUNJUK PENEMPATAN VIDEO PROMOSI EKSKUL EXISEL
=================================================
Letakkan file video promo ekstrakurikuler format MP4 di folder ini:
- Paskibra : public/videos/paskibra-promo.mp4
- PMR      : public/videos/pmr-promo.mp4
- Basket   : public/videos/basket-promo.mp4
- ITC      : public/videos/itc-promo.mp4
- Lainnya  : public/videos/[nama-eskul]-promo.mp4

Video akan otomatis diputar pada halaman detail ekskul masing-masing (misal: http://localhost:3000/eskul/paskibra).
